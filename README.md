# stock-market-app-investo-

📈 Investo

AI-Powered Stock Market Analysis & Chatbot

Investo is an AI-powered stock market analysis application designed to help users understand stock market data through interactive charts and an intelligent chatbot.

The application uses market data obtained through the Groww API and provides AI-based analysis of stock charts, graph patterns, and market movements.

🚀 Features

- 📊 Real-time/market stock data integration
- 📈 Interactive stock price graphs
- 🤖 AI-powered stock market chatbot
- 🔍 Graph and chart pattern analysis
- 💬 Conversational interface for market-related queries
- 📉 Technical analysis support
- 📱 User-friendly dashboard
- 🔐 API-based market data integration

🤖 AI Chatbot

The Investo chatbot allows users to ask questions about stock charts and market patterns.

For example:

- "What pattern is forming on this chart?"
- "Explain this graph."
- "What does this candlestick pattern mean?"
- "Identify the trend in this chart."
- "Explain the support and resistance levels."

The chatbot converts complex chart information into simpler explanations for users.

🔑 API Configuration

Do not upload API keys or other secret credentials directly to GitHub.

Use environment variables or a local configuration file such as:

API_KEY=your_api_key

Add secret files to ".gitignore".

Example:

.env
local.properties
secrets.properties
